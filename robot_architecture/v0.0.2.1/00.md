Every chapter must preserve:

1. ownership
2. lifecycle
3. identity and correlation
4. provenance
5. evidence and uncertainty
6. failure visibility
7. model independence
8. controlled effects
9. observability
10. versioned evolution
11. human control
12. compatibility

## Major v0.0.2.1 additions

The final baseline explicitly integrates:

- persistent cognitive state independent of model context
- explicit memory/experience/learning boundaries
- evidence-based knowledge promotion
- confidence and provenance
- goal/task/plan/action separation
- controlled tool capabilities
- AI Runtime and Model Manager abstraction
- event/correlation architecture
- GUI through the Developer Interface and Control Plane
- configuration and runtime management
- deployment and model provisioning
- architecture-level testing
- controlled self-improvement
- security and trust boundaries
- observability and audit
- future expansion gates

The detailed implementation contracts live in the numbered chapters.
